# 🏏 IPL Complete Analytics Dashboard

A complete **End-to-End Data Analytics Project** built using real IPL datasets. This project demonstrates the entire Data Analytics workflow including data cleaning, exploratory data analysis (EDA), SQL analysis, machine learning, and an interactive Streamlit dashboard.

---

# 📌 Project Overview

This project analyzes Indian Premier League (IPL) match data to generate meaningful business insights. It covers the complete analytics lifecycle, from raw data to an interactive dashboard.

The project includes:

- Data Cleaning using Pandas
- Exploratory Data Analysis (EDA)
- SQL Business Analysis
- Machine Learning Model
- Interactive Streamlit Dashboard
- SQLite Database
- Git & GitHub Version Control

# ▶ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/IPL-Complete-Analytics.git
```

## Move into Project

```bash
cd IPL-Complete-Analytics
```

## Create Virtual Environment

### Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

## Install Packages

```bash
pip install -r requirements.txt
```

## Run Dashboard

```bash
streamlit run dashboard/app.py
```
