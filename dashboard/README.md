# 🏏 IPL Complete Analytics Dashboard


## Project Overview

This project analyzes IPL cricket data to understand team performance, player statistics, scoring patterns and match trends.

The project follows a complete Data Analyst workflow:

Dataset
↓
Data Cleaning
↓
Exploratory Data Analysis
↓
SQL Analysis
↓
Interactive Dashboard


## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- GitHub


## Dataset

The dataset contains IPL ball-by-ball information:

- Match details
- Teams
- Players
- Runs
- Wickets
- Venues
- Seasons


## Dashboard Features

✅ Total Matches Analysis

✅ Total Runs Analysis

✅ Wicket Analysis

✅ Season Performance

✅ Team Performance

✅ Top Batsmen

✅ Top Bowlers

✅ Venue Analysis

✅ Interactive Filters
